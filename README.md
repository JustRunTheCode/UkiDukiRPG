## 📌 Project Overview
This project is a turn-based RPG featuring procedural map progression, dynamic move scaling, complex status effect systems, and headless server-authoritative battle logic. 

While initially inspired by the Nordeus 2026 challenge, the implementation goes beyond the basic requirements to establish an production ready game architecture built with **Unity**, **ASP.NET Core (gRPC)**, and **MessagePack**.
